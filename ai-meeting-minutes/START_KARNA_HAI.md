## 🔧 **Agar Kuch Nahi Dikha:**

### Problem 1: Terminal mein error
```bash
# Check Python version:
python --version

# Agar error, try:
python3 run.py
```

### Problem 2: "Module not found"
```bash
# Dependencies install karo:
cd /workspace/ai-meeting-minutes/backend
pip install -r requirements.txt
```

### Problem 3: Frontend nahi chala
```bash
# Dependencies install karo:
cd /workspace/ai-meeting-minutes/frontend
npm install

# Phir run karo:
npm run dev
```

### Problem 4: Browser mein "Cannot connect"
```bash
# Check dono terminals chal rahe hain?
# Backend: http://0.0.0.0:8000 dikha?
# Frontend: http://localhost:5173 dikha?
```
